# Certified m-independence of the first n zeros of the Riemann zeta function

*Benjamin Weisz (https://github.com/wbeni95), version 1.0.0, 2026-10-25. Licence: CC BY 4.0 (see NOTICE).*

## Statement

Let 0 < γ₁ < γ₂ < … be the ordinates of the nontrivial zeros of ζ(s) in the upper half-plane, and let N = n − 1.

> **Theorem.** For each pair (n, M) in the table below, there is no (m₀, m₁, …, m_N) ∈ ℤⁿ with (m₁, …, m_N) ≠ 0, max_{j≥1} |m_j| ≤ M and
>
>   m₀γ₁ + m₁γ₂ + … + m_N γ_n = 0.
>
> Here m₀ is unrestricted.

| n | M (this work; every relation with max_{j≥1} \|m_j\| ≤ M is excluded) | log₁₀ M | Best–Trudgian 2015, Table 2 |
|---|---|---|---|
| 100 | 26040722142003286077749727759972789806091216009674448694364055279943736769740328079508669202431 | 94.42 | 1.83869·10⁸⁶ |
| 200 | 2593985472748703519351868734915909244539623708 | 45.41 | 1.13717·10³⁹ |
| 300 | 43399658183857302831554515661 | 28.64 | 6.20938·10²¹ |
| 400 | 93622804931216853389 | 19.97 | 2.33172·10¹² |
| 500 | 7713877316725 | 12.89 | 5.54632·10⁵ |
| 700 | 257742 | 5.41 | not given |

**Corollary (m-independence in the sense of Best and Trudgian).** The first n zeros are M-independent for the (n, M) above: every nontrivial combination Σ_{i=1}^{n} c_i γ_i with all |c_i| ≤ M is nonzero.
- Indeed, such a combination with (c₂, …, c_n) ≠ 0 is excluded by the theorem with m_j = c_{j+1}.
- If (c₂, …, c_n) = 0, then c₁γ₁ = 0 forces c₁ = 0.

The theorem is stronger than the corollary, because m₀ is not bounded. Any relation with max_{j≥1} |m_j| ≤ M has |m₀| ≤ (M/γ₁)·Σ_{j=2}^{n} γ_j, so the statement is about a finite box.

**Comparison.** Best and Trudgian [1, Table 2] give lower bounds on the m-independence of the first n zeros for n ≤ 500. The bounds above improve them by 6 to 8 orders of magnitude for n = 100, …, 500, and extend the table to n = 700. We found no later published table (searches up to 2026-10).

## The certificate

**Data.** ν = 32000 and x_j = γ_{j+1}/γ₁ for j = 1, …, N. Let Y_j ∈ ℤ be the integer nearest to 2^ν x_j, computed from rigorous enclosures of the zeros, and put e_j = Y_j − 2^ν x_j. The argument works for any integers Y_j: only the bound on Σ|e_j| is used.

**The lattice.** L ⊂ ℤ^{N+1} is generated by (Y₁, …, Y_N, 1) and the vectors 2^ν ε_j (j = 1, …, N). Equivalently, (v₁, …, v_N, z) ∈ L if and only if v_j ≡ z·Y_j (mod 2^ν) for every j. For each n, the file `bases/LI_n<n>_nu32000.txt.gz` (Zenodo record) contains N + 1 vectors b₁, …, b_{N+1} of L.

**Lemma.** Let b₁, …, b_{N+1} ∈ L be linearly independent, let b*_i be their Gram–Schmidt vectors, and let UB ≥ max_i ‖b*_i‖ and E1 ≥ Σ_j |e_j|. If

  M² (N + E1²) UB² < 2^{2ν},

then there is no relation as in the theorem with max_{j≥1} |m_j| ≤ M.

**Proof.**
1. **Duality.** Let L_s = ℤb₁ + … + ℤb_{N+1} ⊆ L. Then L* ⊆ L_s*, where Λ* = {u : ⟨u, v⟩ ∈ ℤ for all v ∈ Λ}.
2. **Dual length bound** [3; 1, Lemma 3]. Every nonzero u ∈ L_s* satisfies ‖u‖ ≥ 1 / max_i ‖b*_i‖.
   - The dual basis in reversed order has Gram–Schmidt lengths 1/‖b*_{N+2−i}‖.
   - Every nonzero lattice vector is at least as long as the smallest Gram–Schmidt length of a basis.
3. **A relation gives a short dual vector.** Suppose (m₀, m) is a relation with m = (m₁, …, m_N) ≠ 0. Put w = (m₁, …, m_N, −2^ν m₀ − Σ_j m_j Y_j) and u = w/2^ν.
   - Then ⟨u, 2^ν ε_j⟩ = m_j ∈ ℤ and ⟨u, (Y, 1)⟩ = −m₀ ∈ ℤ, so u ∈ L*.
   - Since m₀ = −Σ_j m_j x_j exactly, the last coordinate of w equals −Σ_j m_j e_j.
   - u ≠ 0 because m ≠ 0.
4. **Box maximum.** If |m_j| ≤ M for all j, then |Σ_j m_j e_j| ≤ M·Σ_j |e_j| ≤ M·E1. Hence ‖w‖² ≤ M²(N + E1²).
5. **Conclusion.** Steps 1–4 give 1/UB ≤ ‖u‖ = ‖w‖/2^ν ≤ M·√(N + E1²)/2^ν, which contradicts the hypothesis. ∎

The approach (a reduced basis of this lattice and a lower bound for the dual lattice) is that of Best and Trudgian [1, Theorem 3]; compare also the analysis of integer relation algorithms [2]. The bound with E1 = Σ|e_j| in step 4 is the exact maximum over the box (attained at m_j = M·sign e_j).

## What is computed, and how rigorously

`verify/verify_li.py` checks, for each basis:

| Quantity | Method | Rigour |
|---|---|---|
| zeros | decimal midpoints of γ₁, …, γ₇₀₁ (65536-bit computation, `data/zeros_1_701_midpoints.txt`); \|γ_i − mid_i\| < 2·10⁻⁹⁶⁶⁵ proved for i ≤ 700 by a sign change of Hardy's Z-function at mid_i ∓ 1.999·10⁻⁹⁶⁶⁵, inside a window that lies strictly between the Turing-indexed isolating balls of the neighbouring zeros (FLINT/Arb `acb.zeta_zeros`) | proved; the indexing makes these exactly the first 700 zeros |
| Y_j, E1 | Arb ball arithmetic at ν + 800 bits; E1 is the exact rational sum of the upper endpoints | rigorous upper bound |
| b_i ∈ L | v_j − z·Y_j ≡ 0 (mod 2^ν) for every row and j, exact integers | exact |
| full rank | every ‖b*_i‖² certainly > 0 in the ball LDL (positive definite Gram matrix), and rank modulo the prime 2⁵⁹ − 55 | proved |
| UB² | ball enclosure of every ‖b*_i‖²: rigorous balls around the row entries, ball Gram product, right-looking ball LDL, with the precision doubled until every relative radius is below 2⁻⁴⁰; UB² = max upper endpoint | rigorous upper bound |
| M | the largest M with M²(N + E1²)UB² < 2^{2ν}, exact rational arithmetic | exact |

The program prints, for each n, the largest certified M and whether it is at least the value in the table.

**Independent confirmation.** The values in the table were produced with a first program (an exact integer residual bound for UB). They were then confirmed by the second, separately written program published here, which uses a different arithmetic path (ball LDL). The published program gives M at least as large as the table value for every n (for n = 700: 257743 against 257742).
